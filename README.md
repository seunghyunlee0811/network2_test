# network2_test
# 네트워크관리사 2급 필기 족보 문제은행

브라우저에서 여는 HTML 파일 하나로 동작하는 문제풀이 앱입니다. 서버나 설치 없이 파일을 열기만 하면 되고, 진행 상황은 브라우저(localStorage)에 저장됩니다.

## 데이터

- 문항 **617개** — 2022.02 ~ 2026.05, 18회차 기출을 겹치는 문제끼리 묶은 것
  - 네트워크 일반 117 · TCP/IP 206 · NOS 227 · 네트워크 운용기기 67
- **2회 이상 출제(족보)** 206문항
- 해설이 붙은 문항 321개
  - 직접 작성한 해설 206개
  - 기출 해설집(comcbt 등)에서 가져온 수험생 해설만 있는 문항 115개
  - 두 가지가 같이 붙은 문항 115개
- 지문 그림이 원본에서 누락되어 있어 보기·정답을 근거로 다시 써넣은 문항 20개 — 화면에 `지문 복원 · 원본 누락` 표시가 붙습니다
- 개념카드 70장 — 반복 출제되는 개념과 함정을 정리한 참고 카드

## 풀이 모드 (홈 화면 "풀기")

| 모드 | 설명 |
|---|---|
| **실전 모의고사** | 실제 시험 과목 비율(일반10·TCP/IP17·NOS18·기기5)대로 50문항 랜덤 출제, 100점 만점 채점과 합격선(60점) 판정 |
| **골라서 풀기** | 문항 수(10~50)와 배분 방식(과목 균등 / 실제 비율)을 직접 정해서 그 조합대로 랜덤 출제 |
| **순차 학습** | 출제 빈도가 높은 문항부터 순서대로, **한 번 낸 문항은 다시 나오지 않음**. 전체 또는 과목별로 범위를 정할 수 있고, 진도가 과목별 막대로 표시됨. 범위별 초기화 가능 |
| **오답노트** | 틀린 문항만 모아 다시 풀기. **맞히면 목록에서 빠짐** |
| **틀린 문제 모음** | 한 번이라도 틀렸던 문항 전체. **맞혀도 계속 남음** (오답노트와의 차이) |
| **북마크** | 문제 화면 우측 상단 `☆`를 눌러 담아둔 문항만 모아보기 |
| **과목별 집중** | 과목 하나를 골라 그 과목 문항만 25문항 랜덤 출제 |
| **회차별 기출** | 18회차 각각을 원본 순서 그대로 1~50번 풀이. 실전 모의고사와 동일하게 채점 |
| **개념카드** | 검색 가능한 개념 정리 카드 70장 |

## 설정 (홈 화면 "설정")

- **고르는 즉시 채점·해설** — 끄면 한 회차를 다 풀고 나서야 정답이 표시됨
- **2회 이상 출제만 출제** — 켜면 아래 모드에서 족보 206문항 안에서만 문제를 뽑음
  - 적용됨: 실전 모의고사, 골라서 풀기, 과목별 집중
  - **적용 안 됨: 순차 학습** — 순차 학습은 "전 문항을 겹치지 않게 다 훑는" 목적이라 항상 617문항(또는 과목 전체) 대상. 오답노트·틀린 문제 모음·북마크·회차별 기출도 대상이 이미 정해져 있어 이 설정과 무관

## 저장되는 데이터 (localStorage)

| 키 | 내용 |
|---|---|
| `net2.log` | 문항별 학습 기록 — `s`(푼 횟수) `w`(연속 오답, 0이면 오답노트에서 제외) `t`(누적 틀린 횟수, 틀린 문제 모음에 사용) |
| `net2.cfg` | 설정값 — `instant`, `hotOnly`, `qn`/`qmode`(골라서 풀기), `sn`/`ssub`(순차 학습) |
| `net2.mark` | 북마크한 문항 키 목록 |
| `net2.prog` | 순차 학습에서 이미 낸 문항 키 목록 (진도) |

브라우저 데이터를 지우거나 다른 브라우저·기기에서 열면 진행 상황이 초기화됩니다. 파일 자체에는 진행 상황이 저장되지 않습니다.

## 알려진 제한사항

- **수험생 해설은 검수된 자료가 아닙니다.** 기출 해설집에 실린 여러 사람의 해설을 그대로 가져온 것이라 드물게 틀린 설명이 섞여 있습니다. 명백히 틀린 몇 건은 고쳐서 "틀린 부분 고침" 표시를 붙였지만, 전체를 검증한 것은 아닙니다. 제 해설(`왜 이게 정답인가`)과 다른 이야기를 하면 개념카드 쪽을 기준으로 보는 게 안전합니다.
- **지문 복원 20문항은 원문 그대로가 아닙니다.** 원본 PDF가 이미지 기반이라 지문 그림을 그대로 가져올 수 없어서, 보기와 해설을 근거로 다시 쓴 것입니다.
- 해설이 아예 없는 문항(296개, 대부분 1회만 출제된 문항)은 개념카드로만 연결되어 있습니다.
